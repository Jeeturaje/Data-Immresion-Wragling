# Data Immersion & Wrangling Project

## Objective
To understand, clean, and prepare raw customer data for analysis.

## Dataset
Customer purchase dataset containing demographic and transaction details.

## Data Quality Issues Identified
- Missing values in Purchase Amount and DOB
- Duplicate customer records
- Inconsistent date formats
- Outlier in Purchase Amount

## Data Cleaning Steps
- Filled missing numerical values using mean
- Removed duplicate records
- Standardized date formats
- Created new feature: Customer Age

## Tools Used
- Python
- Pandas

## Output
- Cleaned and analysis-ready dataset
